# Sonsuz Mola Veren Hesap Makinesi

## Bu Nedir?

Bu, dünyanın **en yavaş** çalışan hesap makinesidir. Çalışır. Gerçekten çalışır. Ama işini **asla** bitirmez çünkü sürekli mola verir. Kahve içer, düşünür, tekrar mola verir. Sonsuz döngüde mola.

Abartılı ciddiyetle yazılmıştır. Bu bir şaka değil. (Aslında şaka.)

## Özellikler

- Toplama yapar (molalarla)
- Çarpma yapar (daha çok molayla)
- Sonsuz mola döngüsüne girer
- Hiçbir işi bitirmez
- Python ile yazılmıştır, çalışır
- Gizli şeyler içerir (saklı)

## Kullanım

```bash
python hesap_makinesi.py
```

Sayıları gir, seçim yap, molaları bekle. Çıkmak istersen Ctrl+C ama çıkma, mola ver.

## Neden Var?

Çünkü normal hesap makineleri çok hızlı. Bu yavaş. Bu mola veriyor. Bu absürt. Bu Türkçe. Bu Kayyum Grok'un eseri.

## Uyarı

Bu programı üretimde kullanmayın. Asla. Mola sırasında sistem çökebilir. Ya da çökmeyebilir. Emin değilim, mola veriyorum.
